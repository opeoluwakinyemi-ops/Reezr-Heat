Reezr Heat – deploy on Vercel (free)
1. Put this folder in a GitHub repo, or run "npx vercel" inside the folder.
2. Import it on vercel.com as a static site (no build command, no framework).
3. Open the https link on a phone. Chrome shows "Add to Home screen" / Install.
Live temperature ("Use my location") works once hosted here.
Change cache name in sw.js (reezr-heat-v1) whenever you ship a new version.
